# DAB Pumps

[![IP-Symcon ist da](https://img.shields.io/badge/IP--Symcon-7.0-blue.svg)](https://www.symcon.de)
[![Modul-Version](https://img.shields.io/badge/Modul--Version-1.0-green.svg)]()
[![License](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)

Diese Bibliothek bindet Pumpen von DAB Pumps über die DAB Live Cloud in IP-Symcon ein.

Die folgenden Module beinhaltet diese Bibliothek:

- __DABEsyBox__ ([Dokumentation](DABEsyBox/README.md))
  Liest Betriebsdaten einer DAB E.SyBox (Mini 3, Mini, 2.0, ...) aus der DAB Live Cloud aus.

## Voraussetzungen

- IP-Symcon ab Version 7.0
- DAB E.SyBox mit aktiver WLAN-/Cloud-Verbindung
- DAB Live Account (E-Mail + Passwort)

## Installation

Über den Module Store oder durch Hinzufügen folgender URL im Module Control:

```
https://github.com/mbruckmoser/symcon-dabpumps
```
